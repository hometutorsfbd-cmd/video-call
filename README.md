# Render Ready Video Call

1. Create a GitHub repository.
2. Upload all files.
3. Create a new Web Service on Render.
4. Connect the repository.
5. Deploy.

After deployment:
- Open the site.
- Enter a room ID.
- Share the generated URL.
- Second user opens the same URL.
- Both start camera.
- One user clicks Start Call.

Note: For production reliability, add a TURN server.
